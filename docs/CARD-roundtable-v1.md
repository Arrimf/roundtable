• # Свод раунда roundtable-v1

  **Главный вывод: стол сошёлся в том, что RoundTable — это не передача терминалов, а перенос гарантий (append-only, слепота, blast radius) из дисциплины модели в механику оболочки; анонимность дирижёра в нынешнем виде фикция, сломанная самим журналом; Менеджер-ИИ — главный спор раунда.**

  ## Расхождения

  | Вопрос | Позиции |
  |---|---|
  | Менеджер | **kimi**: нужен — процедурное вето (стоп, откат, смена по таймауту) с записью в журнал; «отклонить диф проще, чем написать». **deepseek, gemini**: лишний этаж — его функции это детерминированный рантайм, а не LLM. **claude**: тест на лишний этаж («назовите решение, доступное Менеджеру, но не пользователю»). **grok**: вето — человека, не ИИ. **codex**: оправдан только при дорогих/необратимых действиях |
  | Динамический допуск к bypass | **claude, deepseek**: за (канарейки + кредит доверия как одно устройство). **gemini**: против — стохастический скоринг ложно успокаивает, изоляция обязана быть безусловным инвариантом |
  | Commit-reveal | **gemini**: математически исключает подгонку на В1. **codex**: нет — вяжет текст, но не влияние до хеширования |
  | Слабый менеджер над сильным | **deepseek, kimi**: безопасен при процедурной роли. **claude**: опровергнуто eyes-pack-v1 — ревью измеренно слабое звено; вето слабого станет штампом |

  ## Единогласно принято
  - bypassV2 (дифы всем) — минимум по умолчанию, не опция.
  - Append-only `room.jsonl` сегодня — соглашение, не механика; дирижёр с write ломает и журнал, и жребий (детально: grok, claude, codex по `choir.py:524`).
  - Жёсткой анонимности нет: `conductor` пишется в pick, имя — в заголовке затравки, стиль демаскирует.
  - MVP — не форк Орки/DSharness, а надстройка: события `grant/revoke/close` в журнале либо отдельная оболочка с адаптерами.

  ## Кто изменил мнение
  - **kimi** — снял своё «ослепление на раунд»: поле в pick делает его нулевым, не временным.
  - **claude** — анонимность и проверяемость несовместимы одновременно, только последовательно (обязательство → раскрытие при close).
  - **codex** — хеш проверяем, журнал доступен (его слепой тезис «сверить невозможно» опровергнут kimi/grok фактами цепочки drand).

  ## Уникальные идеи
  - **claude**: канарейки (ломаные дифы в потоке — bypass зарабатывается); правило второго голоса для графа идей (самовыдвижение запрещено).
  - **codex**: жребий среди готовых планов, не полномочий; одноразовый capability-token вместо постоянного write.
  - **deepseek**: кредит доверия дирижёра; multi-armed bandit для выбора узла графа.
  - **gemini**: commit-reveal В1; Air-Gapped Committer (дирижёр без FS/git, патч из stdout накладывает демон). Слабое место отмечено codex'ом.
  - **grok**: red-team анонимности (голос с eyes обязан назвать conductor); убрать `{who}` из expand и замерить поверхность утечки.
  - **kimi**: commit-reveal самого жребия — `sha256(conductor+salt)` в pick, раскрытие в close.

  ## Нерешённое
  - Механика таймаута: кто детектит, куда переходят права (kimi).
  - Кто классифицирует «вопрос на ту же тему» — тихий рычаг власти (kimi).
  - Канал пользователя сливает личность дирижёра — нужна «китайская стена» реплик (deepseek).
  - Capability matrix: HTTP-голоса (gemini, deepseek) не пишут диск — жребий дирижёра на них роняет этап кода (grok, gemini).
  - Кто пишет журнал, если не дирижёр: внешний писатель/демон — общая дыра всех схем.
