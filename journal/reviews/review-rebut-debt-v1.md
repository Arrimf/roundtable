# Ревизия: долг витка и его добор (2026-10-07)

Решение Автора 2026-10-06: «добери codex/grok через catchup». Диф: `chamber/choir.py` — `rebut_build(a, rebuild=None)`
(сборка пакета витка вынесена из `cmd_rebut`; при `rebuild` — раскрытие, состав и метки из записи unveil того витка,
фокус и пересказ из журнала, ответы только до читавшейся фазы), отказ в витке → `_owe` с `failed_id`, `cmd_catchup`
для фаз rebut* (пакет заново, `packet_same` по prompt_sha записи отказа, `--voice`/`--phase`), `model_passed`;
`chamber/coverage.py` — пометка `packet_changed`; `test/rebut_debt_test.py` (новый, 17); `publish.sh`.
Прогон вживую: grok добран в `jev-v2` на grok-4.7 тем же пакетом (`packet_same=true`, 170 с).

Ревьюеры: deepseek-http, grok-4.7 (в клетке стола), субагент-ревьюер. Codex — квота (usage limit до 01:19), kimi не звался.

## Учтено
- Фазы вне `order` и неизвестная `from_phase` → без трассы (deepseek, grok, субагент).
- Состав и метки добора — из unveil того витка: поздний слепой ответ в пакет не входит, букв сверх раскрытия нет;
  раскрытия только до этой фазы (deepseek, grok, субагент п. 2, 3, 7).
- Фокус и пересказ при rebuild — с `_annulled` (grok, субагент).
- `_owe`: без долга на oversize/missing; повторный отказ той же фазы долг не дублирует (grok, deepseek, субагент).
- `packet_same` — против записи отказа из долга (`failed_id`); долг без неё → `null`, без выдуманной причины
  (deepseek, grok, субагент).
- `model_passed`: deepseek — умолчание argv, gemini — первая модель списка (субагент).
- Карта покрытия: пометка `packet_changed` (субагент).
- Тест: пересказ при rebuild, опоздавший должник, пустой unveil, oversize/missing, двойной отказ, долг без failed_id
  (все трое).

## Не принято / отложено
- deepseek, grok: «при packet_same=false долг всё равно гасится» — так и задумано: ответ получен и записан, а
  отличие пакета названо полем и пометкой карты; не принимать ответ значило бы вечный долг.
- grok п. 6 / субагент п. 3: `nonblind` для должника витка со своим слепым ответом не ставится — верно: в витке
  он слепым и был; при добранном позже слепом ответе состав из unveil исключает его из recs, и он идёт как
  опоздавший с `nonblind` (покрыто тестом).
- Пробник «готов» платный при каждом `catchup` — прежнее поведение, сюда не относится.

## deepseek
дефекты есть

- `choir.py:2395` (`rebut_build`, rebuild): `order.index(phase)` без защиты от фаз вне `order` (например, `"draw"`). Старый код фильтровал `if p in order`; теперь при такой записи — `ValueError`. `last` из `from_phase` тоже не проверяется.
- `choir.py:2432` (`rebut_build`): rebuild заново пересчитывает `labels` из текущих `recs`, а не берёт сохранённые `unv[-1]["labels"]`. Поздний blind-добор, попавший в журнал после витка, меняет состав/буквы пакета, хотя заявлен «тот же пакет».
- `choir.py:3953-3960` (`cmd_catchup`): при `packet_same=false` долг всё равно гасится при ok/pass — только предупреждение. Тем самым добор с изменённым пакетом засчитывается.
- `choir.py:3942` (`cmd_catchup`): `packet_same` сравнивает с `failed[-1]`, найденным по voice/phase/status, а не с конкретной записью отказа из долга (`d["parent"]`). При повторных отказах/долгах по той же voice+phase сравнивается не тот отказ.
- `choir.py:2768-2770` (`cmd_rebut` / `_owe`): пустой `seed_file=""` пишется в долг; защита есть только в rebut-ветке catchup. Повторный отказ в том же витке создаёт второй открытый долг, а `paid` гасит по одному `d["id"]` — возможны дублирующие вызовы `ask_one`/ответы и остаток долга при прерывании.
- `test/rebut_debt_test.py`: тест должен учитывать пробник `ask_one(voice, "Ответь одним словом: готов", "probe", …)` перед основным пакетом, а не ожидать один вызов; также нужны совместимые `hard_timeout`/подмена `cli_version`, иначе тест трогает внешний бинарь или расходится с парсерным default 900.

## grok (grok-4.7)
Дефекты есть.

1. `chamber/choir.py:2401` — при `rebuild` фильтр `order.index(phase)` без проверки `phase in order`. Ответ `ok`/`pass` с фазой вне списка (`draw`, `code`, старое `rebut` без номера) даёт `ValueError`; `cmd_catchup` её не ловит, хвост долгов не добирается. Аннулированные до этой строки уже отсеяны. Обычный виток эту дыру закрывает (`2403`, `p in order`).

2. `chamber/choir.py:2401`, `2419–2431`, `2449–2460`, `3954` — в пакет добора входят все `ok`/`pass` фаз `≤ from_phase`, в том числе поздние слепые, дописанные после раскрытия (границы по времени нет). Новый голос получает букву здесь же (`2454–2460`), в `unveil` витка её нет (`2461` при `rebuild` не пишет). Буквы старых голосов не съезжают. `labels` при этом собираются со всех неаннулированных `unveil`, не с раскрытия этой фазы: в `labels_seen` попадают голоса поздних витков, даже если их нет в промпте. `prompt_sha` может совпасть, и `packet_same` останется `true`.

3. `chamber/choir.py:2483–2484`, `2612–2613` — при `rebuild` фокус и пересказ берутся без `_annulled` (раскрытие и ответы — с ним). В пакет может уйти аннулированный фокус или `digest_used`.

4. `chamber/choir.py:2779`, `1487–1491`, `3915–3979` — долг ключуется тройкой `(round, phase, voice)`, не `id`. Повторный отказ того же витка (все ответы фазы не `ok`/`pass`, либо отказ после аннуляции) пишет второй `debt`. Одна `paid` гасит все такие записи, включая более поздние: после погашения новый отказ в `_debts_open` уже не виден. `catchup` обходит снимок списка и зовёт голос по разу на каждую открытую запись. Пустой `seed_file` на фазе `rebut*` до `find_round_file` не доходит (`3923`).

5. `chamber/choir.py:3949–3963` — `packet_same` сверяется с последним отказом этого голоса в фазе. Неудачный добор сам становится такой записью; следующий успешный добор может получить `packet_same=true` относительно уже уехавшего пакета, а не исходного отказа витка. Долг при этом гасится.

6. `chamber/choir.py:3884–3886` против `3960–3972` — в контракте `cmd_catchup` ответ всегда `nonblind=True`. Для долга витка флаг ставится только если голос в `late_set`; участник со своим слепым ответом добирается как `late` без `nonblind`.

7. `test/rebut_debt_test.py:86` и `chamber/choir.py:3899`, `5487` — тест зовёт `cmd_catchup` с `hard_timeout=None`. Потолок ставится только при истинном значении, поэтому в тесте `HARD_TIMEOUT` не включается. Парсер по умолчанию передаёт `900`. Пробник в тесте подменён вместе с `ask_one`; `cli_version` (`1527`) с этого пути не вызывается. Живой пробник (`3909`) бьёт в бинарь версии и в CLI голоса.

## субагент-ревьюер (сжато до пунктов)
Дефекты есть.
1. choir.py:2401 — при rebuild `order.index(phase)` без `in order` → ValueError на фазах draw/code/rebut.
2. choir.py:2441–2456 + 3961 — поздний слепой ответ, добранный после витка, попадает в recs и получает букву, которой нет ни в одном unveil; labels_seen расходится с картой.
3. cmd_catchup — зависимость от порядка долгов одного голоса: сначала blind, потом rebut → rebuild читает свой поздний слепой ответ, nonblind не ставится.
4. _owe не проверяет открытый долг с тем же ключом — двойной долг, двойной вызов.
5. Долг заводится и на oversize/missing — вечный долг, платный пробник.
6. Фокус при rebuild без _annulled.
7. labels из ВСЕХ unveil, включая поздние фазы — labels_seen утверждает лишнее.
8. packet_same при пустом failed печатает выдуманную причину.
9. model_passed: deepseek всегда получает --model с умолчанием, gemini — список; поле не пишется.
10. coverage: packet_same не попадает в карту.
11. Тест: не покрыты пересказ при rebuild, опоздавший должник, пустой unveil, аннулированный виток, повторный отказ, порядок blind+rebut.
