# Ревизия: кресло секретаря в окне — чат с агентом-посредником (2026-10-08)

Решение Автора 2026-10-08: «не хватает окна чата» ((1)+(2): кресло с полными правами, потом (3) якоря для всех событий).
Диф: `chamber/secretary_turn.py` (новый: реплика Автора → CLI агента с постоянной нитью на проект → события `sec`),
`roundtable.py` (POST /secretary с токеном кресла, резерв хода, GET /secretary + диалог, вкладка: чат, поле токена,
стенограмма хода), `chamber/live.py`, `chamber/choir.py`, `chamber/access.py` (нить и реестр окон скрыты от клетки),
`SECRETARY.md`, `.gitignore`, `publish.sh`, тесты `test/secretary_turn_test.py` (15), `test/voices_http_test.sh` (+12).

Ревьюеры: grok-4.7 (два прохода, в клетке стола), субагент-ревьюер (два прохода); deepseek — ответил служебной
разметкой вызова инструмента вместо ревизии (записано как отказ канала); kimi и codex — квота.

## Учтено (между редакциями)
- БЛОКЕР: POST /secretary без проверки источника → токен кресла (случайный на процесс окна; печатается в терминал;
  отдельный файл 0600 в реестре окон, скрытом от клетки; `CHOIR_RT_SEC_TOKEN` для стендов); отказ — 403 и заметка в
  ленте не чаще раза в 10 мин на клиента, без текста реплики (субагент 1, grok 1).
- Второй проход: токен утекал через GET /windows в карточке — вынесен из карточки в отдельный файл (субагент 2.1, grok 2.1).
- Нить (`journal/secretary`) и реестр окон скрыты во всех клетках: live, choir, access.hidden_roots (субагент, grok).
- Гонка двух POST — резерв под RUN_LOCK до spawn; два окна одного проекта — flock на нить в secretary_turn (субагент 3, grok 7).
- session_id сохраняется только после удавшегося хода; «No conversation found» (по строкам CLI, не по выводу
  инструментов) сбрасывает нить (субагент 4, 2.5).
- Сторож по времени отдельной нитью; CLI без своей сессии — чтобы «Прервать» окна убивал его вместе с группой акта;
  после снятия stdout закрывается (субагент 6, 2.7; grok 3).
- Промпт через stdin; `errors=replace`; потолок в байтах; поле `turn` у отказов; хвост в detail без сырого json
  (субагент 7–9, grok 8).
- UI: ящик чата строится один раз и не снимается с документа; токен читается из поля при отправке и сохраняется по
  вводу; `loadSec` шлёт токен — индикатор честный; стенограмма идущего хода подхватывается, только если Автор ничего
  не выбрал; Shift+Enter — перенос (субагент 10–12, 2.2, 2.3; grok 4–6).
- compare_digest; 409 без «pending»; уборка файлов реплик старше часа (субагент 2.6, 2.9, 2.11).

## Не принято / отложено
- Диалог `sec` виден голосам в клетке через ленту (субагент 2): так и записано в SECRETARY.md — секретов нет по
  решению Автора, в пакет хода он не идёт; скрывать ленту от голосов значило бы ломать комнату.
- Текст ответа в событии без потолка (grok 8): ответ секретаря — содержание, не вывод инструмента; лента и так несёт
  своды по 20 тыс. символов.
- Окно без проекта: агент работает в каталоге стола (субагент 13) — так и задумано: это и есть «стол как проект».
- Токен меняется при каждом запуске окна — названо в SECRETARY.md; хранить между запусками — отдельное решение.
