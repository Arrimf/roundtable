# Ревизия: свой HOME на голос — обязательство 3 (2026-09-18)

Повод: раунд «стол-v3-изоляция» (порядок 4 → 5 → 1+2 → 3). После
cgroup, канареек и клетки bwrap Автор: «го обязательство 3 — свой HOME
на голос». Обещание 3: голоса не читают друг друга. До правки под одним
пользователем каждый голос видел сессии, истории адаптеров и ключи
остальных — ответ слепой фазы ложился в `~/.claude/projects/…/*.jsonl`,
`~/.codex/sessions`, `~/.kimi-code/sessions`, `~/.grok/sessions`,
`~/.gemini/choir-http`, `~/.deepseek/choir-http` сразу, до закрытия
фазы.

Сделано:
- `chamber/jail.py` (переехал из корня RoundTable/ — клетка свойство
  комнаты, копии `chamber/` в тестах должны её видеть). HOME не
  подменяется (auth и `recover` — раунд назвал подмену упущением всех);
  вместо этого дом — пустой tmpfs, в нём только своё (итог круга 2;
  первая редакция закрывала соседей поимённо `--tmpfs`/`/dev/null`);
  РОДИТЕЛИ чужого под открытым ro (`journal/voices/`, `~/.cache/choir-voices/`,
  карантин `~/.cache/choir/`), поверх — только своё (rw каталог голоса,
  ro каталог своего вызова, свой cwd). `unset_env()`: чужие ключи
  (`SECRET_ENV`), ничьи (`SECRET_ENV_RE`: `*_API_KEY`, `*_TOKEN`,
  `AWS_*`, `GITHUB_*`…), адрес D-Bus. `--unshare-pid`, `--unshare-ipc`,
  tmpfs поверх `/run/user/<uid>`. `base_voice()`: kimi-alt → kimi.
  `wrap(nest_own=True)`: Кодекс в клетку со своей песочницей внутри
  (`bwrap+own`; вложение замерено живьём). `path_tmp_dirs()`: PATH под
  /tmp — ro (стабы тестов). `mark()`: строка стенограммы. Порядок
  `prefix`: корень → ro → сокрытия → rw → ro_after → unsetenv → chdir.
  `CHOIR_RT_JAIL_REQUIRED=1` — строгий режим.
- `chamber/choir.py`: свой каталог на вызов в карантине
  (`QUARANTINE/<stem>/{prompt,answer}`, fifo внутри; уборка в finally);
  `_call` → `jail.wrap(ro=[SANDBOX, PROJECT], hide=_hide_dirs(),
  ro_after=[cdir, cwd], nest_own=True)`; факт в записи голоса (`jail`,
  `jail_sha`); шапка стенограммы + `mark`; `_sweep_stale_quarantine`
  убирает плоские `*.prompt/*.answer` прошлых версий.
- `chamber/live.py`: `turn` → `jail.wrap(rw=[home], ro=[JOURNAL,
  PROJECT], hide=_hide_dirs(), ro_after=[cwd] если cwd не home)`; факт
  в событии при любом исходе; `_note` с «🔒»/«⚠ без клетки».
- `roundtable.py`: `jail`, `jail_sha` в записях раунда; метка в
  карточке раунда. `executor_run`/`merge_gate` импортируют из chamber.
- `test/jail_test.sh`: 79 проверок (сквозные ходы комнаты через
  `live.deliver` и раунда через `choir.ask_one` со стабом codex: чужое
  состояние пусто, `~/.claude.json` под /dev/null, поздний сосед не
  виден, `/proc` без соседей, карантин — только свой каталог,
  `XDG_RUNTIME_DIR` пуст, чужой и ничей ключ сняты, свой остался,
  настоящий диск ro, событие и запись несут факт). `executor_test.sh`:
  внук в клетке умирает с pid-namespace, без клетки (codex, own) —
  переживает, обе границы закреплены. `chamber/CLAUDE.md` — раздел.

Живьём (одноразовые дешёвые вызовы): codex внутри bwrap (`bwrap+own`)
отвечает, 3–4К токенов; kimi, grok (pty), claude fable, dsh — с
pid/ipc namespace и tmpfs поверх `/run/user` отвечают «ОК»; комната на
копии журнала: deepseek (`bwrap`, 10 с) и codex (`bwrap+own`, 10 с)

Формат: мини-ревизия read-only, четыре круга (codex, grok, kimi,
deepseek, gemini-http; субагент построчно с прогоном тестов и пробниками
