## Ревьюер: субагент-ревьюер, построчно, с прогоном тестов. 5 замечаний, все учтены
1. **Правило 8.5 не выполнялось**: запасной жребий свода (ведущий не свёл) выбирал
   среди всех ответивших, включая отдыхающего; `summarize` без `--by` и окно взяли
   бы его из записи. Теперь `lot_rest(rnd)` читает поле `rest` из ЗАПИСИ ЖРЕБИЯ
   (не из памяти и не из среды), и запасной жребий его исключает.
2. `summarize --by gemini` проходил без слова — теперь код 2; снять честно можно
   только явной переменной `CHOIR_LEAD_REST`, видимой в среде.
3. Опечатка в `CHOIR_LEAD_REST` молча снимала отдых — теперь неизвестные имена
   останавливают с сообщением, как у `--exclude`.
4. Сообщение такта о коде 2 не называло новую причину — дописано.
5. Документ обещал «обеспечено механикой» раньше, чем это стало правдой, — после
   пунктов 1–2 формулировка сходится с кодом; уточнена.
