# Ревизия: причины отказов ACCESS.txt — в ленте, под кнопкой, в подсказке (2026-09-22)

Повод: Автор по событию 961 («отвергнуто строк: 1 — что там отвергнуто?
можно отображать во всплывающей подсказке»). Отвергнута была строка
`rw ~/AiSandbox/RoundTable/` — правило 5 механикой: стол на
запись голосу не выдаётся.

Сделано: текст события `access` несёт причины словами (обрезка 600 с
многоточием, поле `rejects` полное); строка под кнопкой и подсказка
поля повторяют отказы; без отказов подсказка возвращается к исходной
(`dataset.title0`); при любом раннем выходе загрузки подсказка
сбрасывается; потолки длины у подсказки (1500) и строки (600). Тест
окна: текст события с причиной, 20 отказов → ответ полный, текст
обрезан с «…», `node --check` JS страницы.

Формат: вер1 — пять read-only вызовов по пакету с дифом (codex,
deepseek-http, gemini-http, grok, kimi через ворота) + субагент
построчно. Время: codex 8 с (упал), gemini 65 с (упал), kimi 119 с,
deepseek 121 с, grok 154 с; субагент 226 с.

### grok

Проверяю правку на инъекции, экранирование и порядок вызовов `accessShow`/`loadAccess`.Проверяю ранние выходы `loadAccess` и экранирование ленты ещё раз — похоже на застревание `title`.**`roundtable.py:6617`, `6620–6621`** — после проекта с отказами ранний выход `loadAccess` (пустой «Проект», сеть, `!r.ok`) обновляет `accessNote`, но не трогает `accessTa.title`: подсказка продолжает показывать чужие ОТВЕРГНУТО. Инъекция: лента через `esc`, подпись/`acterr` через `textContent`, `title` — свойством (не атрибутом в HTML-строке); кавычки/`<>`/перевод строки из текста Автора в XSS не выходят. `dataset.title0` пишется до `loadAccess()`; проект без файла идёт в `accessShow` и возвращает исходную подсказку.

• ДЕФЕКТОВ НЕТ

  Проверено по точкам риска:

  - **Инъекция/экранирование.** Отказы содержат сырую строку Автора (`access.py:251,255` — `строка {n} «{line}»: {why}`), но все стоки безопасны: лента рендерит текст через `esc()` (roundtable.py:5791), `acterr` и `accessNote` — через `textContent` (6873, 6610), подсказка — через DOM-свойство `accessTa.title` (6613), HTML не парсится. Кавычки/переводы строк/HTML не ломают разметку; переводов строк в отказе нет по построению (`splitlines`).
  - **Приоритет операторов** (roundtable.py:4957-4958): `A + B if C else D` разбирается как `(A+B) if C else D` — скобки верные; `[:600]` режет именно склеенные отказы, а не всё событие.
  - **dataset.title0** снимается при загрузке скрипта (6605), до первого `loadAccess()` (6638) и до любого `accessShow` — порядок корректен, исходная подсказка из разметки (5383) восстанавливается при отсутствии отказов.
  - **Проект без файла**: `rejects` пуст → подсказка возвращается к `title0`, заметка честно пишет «ACCESS.txt в проекте нет» (6608). Случай «файл — ссылка» попадает в `rejects` и показывается.
  - **Тест**: ожидание `«отвергнуто строк: 3 — строка »` совпадает с форматом `строка {n} «…»: …`; `не существует` — из `_why_reject`.

  Замечания (не дефекты): подсказка и `acterr` не ограничены по длине (обрезка 600 — только в ленте); при ошибке загрузки после смены проекта title хранит отказы прежнего проекта, пока `loadAccess` не отработает успешно.
