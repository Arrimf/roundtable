# Ревизия: Грок потоком событий (сторож тишины больше не снимает думающего) и токен кресла на проект (2026-10-08)

Повод: наказы Автора 2026-10-08 (событие 1624): «давай займёмся вылетающим
Гроком — он часто пропускает»; «токен то во всех окнах, то не во всех —
пусть на каждый проект свой».

Диагноз Грока (до правки): десять снятий `stalled` за 25.09–08.10. Журналы
сессий самого Грока за три снятия 08.10 показывают события каждые доли
секунды до снятия — работал; в формате plain stdout молчал, и сторож
тишины (300 с) его снимал.

Правка: `chamber/grokstream.py` (новый: ответ, сообщения CLI, тонкая
стенограмма), Грок с `--output-format streaming-json` в `choir.py`,
`live.py`, `secretary_turn.py`; квота и причина отказа — по сообщениям
CLI; канарейка; восстановление из сессии; окно рисует поток.
`roundtable.py` — файл токена на проект, общий файл не раздаётся,
браузер хранит токен под ключом проекта, токен считается после разбора
`--project`. Тесты: `grokstream_test` (14), `grok_render_test.js` (6),
`secretary_turn_test`, `voices_http_test` (181).

Ревьюеры: субагент (построчно, офлайн-тесты), grok-4.7 в клетке (вер1).
Живая проба: Грок в кресле секретаря под pty — мысли, инструмент и
верный ответ.

## Найдено и учтено

1. **Ложная «квота» из мыслей и вывода инструментов** (оба): квота
   искалась по всему stdout, а там теперь мысли и вывод прочитанных
   файлов; снятый по тишине Грок с «429 … limit» в прочитанном файле
   записался бы `quota` вместо `stalled`. Теперь — только по сообщениям
   CLI (`grok_stream_diag`: не-JSON строки и события `error`). Тест
   показывает: по сырому выводу ложная квота ловится, по сообщениям — нет.
2. **Причина отказа пропадала** (оба): под pty stderr Грока пуст, а разбор
   выбрасывал сообщения CLI — в комнате «error, код N» вместо
   квоты/входа/занятости, в раунде пустой `detail`, у секретаря хвост без
   событий `error`. Сообщения CLI добавляются к причине при отказе.
3. **Склейка дельт в окне не работала внутри одной порции** (оба):
   `isConnected` у узла во фрагменте ложен — каждая дельта становилась
   отдельным куском без переводов строк. Проверка «узел в #term ИЛИ во
   фрагменте этой порции»; любая не-дельта закрывает строку (раньше
   ранние return шапок и итогов голоса оставляли её открытой). JS-тест.
4. **Строки вывода инструмента в десятки КБ** (оба): байтовый массив
   `rawOutput` раздувал стенограмму и строку больше порции чтения окна —
   JSON резался посреди, вкладка показывала сырьё, чистка выдачи не
   видела секретов в байтах. Стенограмма получает тонкую строку
   (`slim_line`): без массива, вывод обрезан до 1500 символов с пометкой.
5. **Восстановление из сессии склеивало куски иначе** (субагент): режет
   по вызовам инструментов так же, через пустую строку.
6. **Канарейка Грока ушла бы в unclear** (субагент): реплика перед
   инструментом стала первым абзацем; для Грока вердикт ищется в первом
   абзаце после неё, строгость самой строки та же.
7. **Комментарии противоречили друг другу** (субагент): в plain шёл текст
   ассистента, а не мысли; ссылка `live.grok_stream_answer` → `grokstream`.
8. **Общий токен раздавался каждому проекту бессрочно** (оба): «свой у
   проекта» до первой смены был одним секретом, сменённый жил бы в
   будущих проектах. Общий файл не раздаётся и удаляется; каждый проект —
   свой новый токен.
9. **Токен считался до разбора `--project`** (поймал стенд окна): файл
   брался для каталога запуска. Считается в `main()` после разбора.
10. **Браузер хранил токен под одним ключом на порт** (grok): тот же порт
    с другим проектом слал бы чужой токен. Ключ — проект (`/state.sec_key`).
11. **«Флак» проверки якоря** объяснился: тест слал реплику, пока стаб
    прошлого акта ещё отвечал («уже отвечают: claude»). Тест ждёт простоя
    и называет причину, если не дождался.
12. Устаревшие «во всех окнах» в комментариях и подписях исправлены.

## Названо, не правится

- Кресло исполнителя и ревизия зовут Грока plain: там свои сторожа;
  перевод — отдельным шагом, если снятия повторятся там.
- Частичный текст снятого Грока остаётся в записи со статусом не-ok — как
  у остальных голосов; в пакеты витков не идёт.
- Окна старого кода держат старый файл токена до перезапуска; после
  перезапуска каждому проекту — ввести его токен один раз.
