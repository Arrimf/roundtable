## Найдено и учтено

1. **`pokeSec`/`fillActs` недоступны из обработчика галочки** (оба): они
   внутри IIFE вкладок, `typeof` давал undefined — вкладка секретаря и
   список актов обновились бы только по таймеру. Перерисовка вынесена
   одной функцией `window.applyTsFull` внутри IIFE (диалог, список актов
   вне ленты, открытая панель окон).
2. **Сброс `dataset.sig` у чужого элемента** (оба): `renderActs` держит
   подпись на `#actlist` и времени не рисует — строка убрана.
3. **Время в списке актов врало по запасному пути** (оба): `o.ts` —
   момент, когда окно увидело акт; идущие акты после перезагрузки
   показывали бы время открытия окна. `loadActs` теперь кладёт серверное
   время старта в `o.at`; `at` из событий — только у «принят»; без
   старта — «~» и момент первого показа, не выдаваемый за старт.
4. **Развёрнутый ответ схлопывался через ≤15 с** (субагент, grok):
   вкладка перестраивается по таймеру и на каждое событие. Раскрытые
   ключи помнятся в `SEC_OPEN` (по id события/отчёта).
5. **Порядок элементов свёрнутой строки** (оба): «права полные», «⚓» и
   кнопка якоря вставали под блочным телом с висящим « · ». Тело —
   последним (`d._body`).
6. **Пустая первая строка и отказы** (оба): текст с ведущим `\n` или
   `text=""` + `detail` давал пустую свёртку, причина отказа пряталась.
   Первая непустая строка; отказы и реплики Автора — целиком.
7. **`fillActs()` на ленте стирал стенограмму** (субагент): пустой набор
   → `startTerm(null)`. Список обновляется только вне ленты.
8. **Агент диалога по умолчанию `claude`** (оба): при другом посреднике
   метка ложная, а по ней передаётся роль. Без `--agent`/`SECRETARY_AGENT`
   — отказ словами.
9. **У реплики Автора нет `recorded_by`** (субагент): текст Автора кладёт
   агент — помечено, как у decision (правило 3).
10. **Файлы диалога мимо `_read_text`** (оба): нет файла — трасса.
    Теперь отказ словами.
11. **`late` не виден во вкладке** (grok): метка « · задним числом» —
    время события есть момент записи, не разговора.
12. **Тесты** (оба): поле `late` без флага, `rights` у реплики Автора,
    агент из среды, отказ без агента, нет файла, «ни реплики, ни
    ответа», счёт событий до/после. Блок якоря в `voices_http` ждёт
    событие, а не 2 с (флак на длинной ленте).
