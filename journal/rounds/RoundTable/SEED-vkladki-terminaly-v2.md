# Раунд: вкладки-терминалы-v2 — Отображение внутренней кухни и хода мыслей моделей в UI

### Контекст
Автор стола предложил идею: в интерфейсе RoundTable (`roundtable.py`) рядом с основной лентой чата сделать вкладки для каждого вендора с живым отображением их «внутренней работы / размышлений в процессе».

**Текущее положение дел:**
- Каждый ход — это отдельный запуск процесса (CLI: `claude -p`, `codex exec`, `grok` через pty, `kimi -p`; либо HTTP-адаптеры: Gemini, DeepSeek).
- Их `stdout`/`stderr` пишется в файлы актов `~/.cache/choir/rt-acts/<act>.log` и сейчас скрыт от интерфейса (браузер видит только финализированный `live.jsonl`).
- Характер потока у всех разный: у Claude и Codex есть структурированный stream-json/события; у Grok — сырой pty; у DeepSeek/Gemini — reasoning/thinking-блоки API; у Kimi промежуточных событий нет.
