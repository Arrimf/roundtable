# СВОД двух раундов В1: вкладка «исполнители» и канал Дипсика (2026-09-01)

Дословные ответы — в `раунды-в1/t1-*.txt` (вкладка) и `t2-*.txt` (dsh).
Состав: codex, grok, kimi (по пакету), deepseek, gemini, голос claude;
во втором раунде Дипсик отвечал ОБОИМИ каналами параллельно.

## Раунд 1 — вкладка «🔧 исполнители»

**ГЛАВНОЕ РАСХОЖДЕНИЕ — С АВТОРОМ, 6/6.** Предложение «"он же
исполнитель" по умолчанию ВКЛ» отклонили все шестеро: «инверсия
безопасного дефолта — самый частый жест окна становится платной правкой
с правом записи» (kimi), «привычный confirm прокликивается за неделю»
(claude), «на модальное окно кликают машинально» (kimi). Компромиссы
вместо голого confirm: кнопка меняет имя и цвет при ВКЛ (claude);
двухрежимная кнопка «читать/писать» с ценой на ней (deepseek); confirm
называет действие — «Запустить платную правку», не «ОК» (codex); write
только при заявленном скоупе (gemini); подтверждение по цене ошибки —
кресло одним OK, а Принять/Adopt вводом id акта (grok).

**Единогласно ЗА:** сама вкладка (правки — третий режим окна); статус
акта + кворум ревизии + карантин видны ПОСТОЯННО, во всех вкладках
(«состояние с деньгами и правом записи, убранное по клику, молча
протухает» — claude); рандом исполнителя остаётся, но только из
дешёвых (kimi — лишь явно; уже так в коде).

**Спрятать глубже:** батч и Adopt — единогласно; скоуп — спор:
claude/deepseek «на виду», gemini/codex «детали глубже».

СВОИ ИДЕИ: **лента актов** вместо панели кнопок — каждый акт строка со
стадиями «кресло → диф → ревизия N/2 → merge», кнопка существует только
на легальной стадии (claude); ценник правки до запуска (kimi);
предохранитель первого движения — первая правка требует скоупа (codex);
авто-исполнитель по последнему одобрившему вердикту (gemini).

## Раунд 2 — HTTP или dsh за столом

**ЕДИНОГЛАСИЕ 7/7, включая оба «я» Дипсика.** За столом — HTTP; dsh —
в креслах (исполнитель, контролёр гейта). Сам Дипсик: HTTP-канал —
«dsh — только опциональный сенсор по флагу»; dsh-канал — «гибрид уже
собран правильно — не менять: голос стола обязан быть воспроизводимым
и честным по затратам, а потеря его истории при сбое — потерянный
голос раунда». Грок: «прослойка, которая сама решает, уже врала —
Gemini CLI молча подменял модель».

**Рычаги, предложенные к главному минусу HTTP (нет агентности):**
live-штамп свежести в пакете — sha и перечень изменений после упаковки
(codex + deepseek-http, сошлись независимо); context caching DeepSeek
— срежет задержку и цену HTTP (gemini); контрольный вопрос обоим
каналам как датчик деградации упаковки, расхождение включает dsh-аудит
следующих раундов (codex, СВОЯ ИДЕЯ).

**Решение по раунду 2 готово к исполнению без правок кода: оставить
как есть.** Раунд 1 ждёт решения Автора по умолчанию галочки.
